生成式 AI / 虚拟角色

像伴

上传一张人物照片，生成保留本人特征的轻 Q 全身虚拟形象，再让角色用拟人语音陪用户聊天。

角色支持文字对话、语音回应与局部眨眼；嘴型由真实语音包络驱动，不再按固定节奏机械开合。生成、聊天与形象展示被整理成普通人能直接完成的一条本地流程。

形象
人物照片 → 轻 Q 全身虚拟形象
动效
局部眨眼帧 + 真实语音包络驱动嘴型
形态
本地运行应用，角色数据保存在本机

个人自用与朋友分享工具，不公开 API Key、私人照片或聊天内容。调用生成与对话模型时仍需上传必要内容；应用会在使用照片前完成确认，并对访客数据做隔离。

计算机视觉 / 创作工具

隔空手势画图

把摄像头里的手部动作变成画笔，在不接触键鼠的情况下完成选色、绘画、擦除与撤销。

在 MediaPipe Hands 输出的 21 个手部关键点基础上重做浅色创作工作台，加入笔触级撤销、独立绘图层、双手分工与 One Euro 平滑。OpenCV 负责最新帧读取、工具栏命中、局部画布合成和实时反馈。本轮还加入 Windows 原生 DPI 显示适配和两帧手势确认，减轻界面缩放模糊与起笔延迟。
